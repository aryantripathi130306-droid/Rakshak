BSA §63 Forensic Evidence Integrity Verification Checklist

Every digital evidence asset ingested into Rakshak must satisfy the statutory standards of the Bharatiya Sakshya Adhiniyam, 2023 (Section 63) for electronic records admissibility in court.

✓ 1. Client-Side Pre-Ingestion Hashing
Original byte stream SHA-256 digest is calculated directly in the officer's browser via WebCrypto API before network transmission.
✓ 2. Server-Side Independent Verification
Backend receives raw bytes and independently computes SHA-256 via Node.js crypto module. Mismatches are rejected with HTTP 422.
✓ 3. Write-Once Content-Addressed Cold Storage
Immutable raw binaries stored at /uploads/raw/<sha256>.bin. Files are never overwritten or mutated by preview/export actions.
✓ 4. Deterministic Fact Extraction & Syndicate Linking
UPIs, phone numbers, IFSCs, and UTRs extracted deterministically, linked to source SHA-256 hash, and correlated across syndicate cases.
✓ 5. Append-Only Chain of Custody Logging
All intake, verification, audit, access, and download events are permanently recorded in the database with timestamps and actor identities.
